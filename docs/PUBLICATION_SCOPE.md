The public repository is a clean, standalone publication. It does not change access to the original production repository or the separately hosted private review Site. No open-source license or broader right to redistribute third-party materials is granted.

Future additions must remain within this scope or be separately reviewed and authorized. Source license status can change independently of an unchanged deal. Unknown redemption scope does not mean the deal is invalid, and export age is not treated as expiry.
