# Third-party notices

This showcase uses Python's standard library, plain JavaScript, HTML, CSS and
inline SVG. It bundles no third-party software dependencies, fonts, map tiles,
retailer artwork, photographs, or provider route/geocoding output.

The source schemas reference the JSON Schema 2020-12 specification. The public
facts sample contains retailer names, license identifiers, recorded license
status and short advertised terms selected from the existing HGC bridge.
Retailer names are used for identification; no endorsement is implied.
Third-party facts and terms are not claimed as HGC's copyrighted property.

Original raw directory and birthday exports are not distributed. All real
street addresses, coordinates, geometry and provider-derived data are excluded.
The geographic numbers in algorithm tests are mathematical test inputs, not a
published geocoded location dataset. The browser lab uses fabricated unitless
points and does not route to retailers.

These notices describe this specific distribution, not the production
application's dependency or data inventory. Additional source files, assets or
data require their own review before being added.
